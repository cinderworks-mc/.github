# cinderworks

mods for minecraft, made for anyone to use. we also run a couple of small servers and packs for our own friends.

## mods

- [plinthworks](https://github.com/cinderworks-mc/plinthworks): pedestal automation. teach a plinth to move items, energy, fluids and xp, filter them, break, place and harvest blocks, and link plinths across distance.
- [nullspace](https://github.com/cinderworks-mc/nullspace): a pocket workshop for every player, reached through tempad gateways. each player gets an archive room that grows as you feed it materials. not released yet.
